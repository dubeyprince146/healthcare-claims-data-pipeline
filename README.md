# Healthcare Claims Data Pipeline

## Project Objective

This project builds an end-to-end data pipeline for processing synthetic healthcare claims data. It validates claim records using Python, stores source files in AWS S3, loads the data into Snowflake, and prepares clean data for analysis.

## Planned Data Flow

Generated CSV files → Python validation → AWS S3 → Snowflake raw tables → SQL transformations → Curated claims tables

## Technology Stack

- Python
- SQL
- AWS S3
- Snowflake
- Git and GitHub

## Current Status

The local repository, Python virtual environment, Git version control, and private GitHub repository have been configured. Basic Python and Snowflake SQL exercises have also been completed.
